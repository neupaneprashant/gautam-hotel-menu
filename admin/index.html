Edit the menu

Sign in with your GitHub access key to change prices and dishes. Changes go live on the menu about a minute after you publish.

How do I get an access key?
  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Token name: Gautam menu admin. Expiration: choose how long it should work (e.g. 1 year).
  3. Repository access: “Only select repositories” → pick the menu repository.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Tap Generate token, copy it, and paste it above.

The key only works for this one menu. Anyone who has it can edit the menu, so share it only with staff you trust. You can delete it on GitHub at any time.

Price tips: type a number like 250, two prices like 185 / 380, or leave it empty to show “Ask staff”. In price tables, leave a box empty if that size or type isn't sold.
